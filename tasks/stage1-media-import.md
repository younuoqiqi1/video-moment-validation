## 执行步骤

1. 同步最新 `origin/main`，先检查本地 Git 工作区和 AGY/App 状态；保留已有用户改动。
2. 只检查项目配置的素材目录（优先 `data/input/`）和用户已指定的素材位置，不要递归扫描整个用户目录。用本机 FFmpeg/ffprobe 读取媒体。
3. 若找到可用的 20–30 分钟素材，生成素材清单：稳定的素材 ID、时长、画面尺寸、帧率、编码格式、音轨/字幕情况；再生成带起止时间码的镜头/场景清单，便于之后逐项预览。先处理一条素材，优先《潜伏》相关素材。
4. 若没有可用素材，或素材格式无法读取，记录具体阻塞和建议的最小操作，不要猜路径，也不要把素材上传到云端。
5. 添加或更新测试，验证格式识别、时间码边界、错误提示等可独立测试部分；测试媒体使用合成短片，不依赖真实剧集。
