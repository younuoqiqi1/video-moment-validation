# 素材准备任务：下载用户指定视频

日期：2026-09-30（Asia/Shanghai）
授权：用户要求通过 Git 向本地 AGY 下达素材下载任务。
状态：ready；这是一项独立素材准备任务，不代表其他阶段已验收。

## 目标

在用户 Mac 本地下载 https://youtu.be/dNpniZ1QJiw 到本项目 data/input/，供后续视频能力验证使用。不要在云端执行。

## 执行要求

1. 先检查 Git 状态，保留用户已有工作；安全拉取任务，不强制覆盖、不重置、不强推。
2. 检查是否已有可用下载工具。优先使用已有 yt-dlp；若缺失，可将 yt-dlp 安装到项目 .venv，禁止全局或系统安装。已有 FFmpeg 可用于合并音视频。
3. 先读取标题、时长、可选格式和字幕列表。核对是否为《潜伏》30集版本的第18集；当前 Codex 无法访问链接，尚未验证标题和集数。若明确不是目标集，先报告，不擅自更换链接或把其他视频标成第18集；无法确认时如实标注。
4. 对目标视频优先选择不超过1080P的MP4，保留原始音轨；不能满足时报告实际可用格式，不伪造1080P。不要剪辑素材或开始后续阶段。
5. 如有中文字幕一并保存，区分人工字幕和自动字幕；无字幕不算下载失败。画面内嵌字幕与独立字幕文件需分开说明。
6. 视频、音频、字幕文件、cookies和凭据仅保留本地，不进入Git。检查忽略规则并逐项暂存报告，禁止 git add .。
7. 遇到登录、验证码、权限或地区限制，报告 blocked；不绕过限制、不上传或打印凭据。如需用户操作，说明最小必要步骤。
8. 成功后用 ffprobe 核对文件能读取且包含音视频流，记录实际时长、分辨率、格式及本地相对路径。
